ONE SMALL SETUP

Bring your studio to life.

The example is ready to explore. New edits need an OpenAI API key with billing and image-model access.

  1. Copy .env.studio.example to .env.local in this project.
  2. Add your key after OPENAI_API_KEY=. Keep it private.
  3. Restart with npm run studio, then refresh this page.

Your key stays on the local server. Clicking Create sends your photo and the style references to OpenAI for a paid API edit.
